Step A: Styling Approach

Tailwind v4
→
:root custom properties

Tokens live as CSS custom properties in :root (dark) and [data-theme="light"]. Components reference them via style={{ color: "var(--text)" }}. Tailwind handles layout, spacing, and responsive utilities. The theme toggle swaps the data-theme attribute on <html>.

Step F: Responsive Plan

Where the layout changes, and to what.

BreakpointLayout Change
Below 640px (phone) Full-screen graph canvas. Details panel becomes bottom sheet (rounded top). Header toolbar collapses to overflow menu (3-dot). Modals are full-width bottom sheets. Cards stack vertically. No sidebar.
Above 640px (tablet/desktop) Details panel sits beside graph (right side, 320px wide). Header shows inline toolbar buttons. Modals are centered dialogs (max-width 480px). Discover grid shows 2 columns.
Above 1024px (wide desktop) Full sidebar with rich person details. Discover grid shows 3 columns. Larger modal sizing. More breathing room around graph.
Hard Requirement
No horizontal scrolling on a 375px-wide phone (iPhone SE). Canvas scales to viewport width.

Design Principles Summary

Visualise Relationships
The graph is the core UX — connections are shown, not just listed. Every design decision supports spatial understanding of your network.
Dark-First Atmosphere
Deep navy backgrounds with violet accents create a focused, modern feel. Light theme is available but dark is the primary experience.
Consistent Token System
Every colour, size, and spacing value comes from a token. Components never hardcode values — they reference CSS custom properties.
